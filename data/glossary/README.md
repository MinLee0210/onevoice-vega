# data/glossary

- `termbase.tsv` — VI/EN/ZH/KO industrial termbase (~40 concepts). Translations
  are a **draft** and need native-speaker review before shipping.
- `hard_examples.jsonl` — generated by
  `scripts/edge/build_glossary_hard_examples.py`: VI→EN pairs where base
  Opus-MT mis-translates the required glossary term (training set for
  `scripts/edge/finetune_mt_glossary.py`). Rebuild after editing the termbase.
